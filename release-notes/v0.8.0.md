# Apogee v0.8.0

- **Export your wallet's descriptor and public data.** A new screen under
  Settings hands you everything about a wallet that does not require its seed:
  the account key, the watch-only descriptor that recreates it elsewhere, the
  master blinding key, and a public descriptor with that key removed. Values are
  grouped by what they disclose rather than listed flat, because the difference
  matters: one group reveals which addresses are yours, the other reveals every
  amount you hold, permanently. Nothing in either group can sign or spend, and
  your seed phrase is never included. Works for a local-seed wallet, a paired
  Jade, and an imported watch-only wallet, which is the case where it matters
  most since there is no seed phrase to fall back on. Per-wallet text file, or
  every wallet as JSON. See
  [`docs/wallet-descriptor-export.md`](../docs/wallet-descriptor-export.md).
- **The balance behaves like an instrument, not a label.** The telemetry numerals
  strike like a neon sign when a figure changes, on sync and when you toggle
  between sats, LBTC and fiat, and the whole balance folds away as the history
  scrolls so the list gets the room. An Animations switch in Settings turns the
  motion off for anyone who would rather it did not move, and the wallet already
  respects the system reduced-motion preference.
- **Trusted Simplicity Lending transactions.** Event-discovered dapps can ask
  whether Apogee recognizes the built-in Lending v3 manifest, then request any
  of its eight supported lifecycle actions. Apogee independently resolves chain
  state, selects wallet inputs, constructs and dry-runs the covenant transaction,
  shows the exact effects for approval, signs, broadcasts, and safely resumes an
  interrupted broadcast. Verified action hints restore human-readable lending
  activity from the seed. This first release is deliberately restricted to
  Liquid testnet software wallets; Jade, mainnet, partial repayment, and remotely
  installed manifests remain follow-up work.
- **Your transaction history as a CSV.** Every transaction with its date, txid,
  amounts, assets and fee, one row per asset moved so a swap reads as the two
  sides it actually is. Amounts appear both in base units and scaled, so a
  spreadsheet can add them up without losing precision, and the raw asset id is
  always present because a ticker can be missing or repeated. Confirmed and
  pending transactions both, marked as such.
- **Connect a hardware wallet is a button again.** It had been demoted to a text
  link so the onboarding chooser could look the same on Firefox, which cannot
  talk to a Jade at all. Firefox is gone, so pairing a Jade is a first-class path
  on the only browser Apogee ships to and now reads as one.
- **The L-BTC row says what its number is.** In the Assets list an L-BTC balance
  shown in sats sat under a label reading "LBTC", so 989,411 sats could be read
  as 989,411 LBTC. The figure now names its unit.
- **A seed QR that a Jade can actually read.** Exported seed QR codes were
  rendered too bright for the device's camera to lock onto. The export now
  carries a brightness control, so moving a wallet onto a Jade no longer depends
  on the screen you happen to be using.
- **Coins survives leaving the screen.** A consolidation in flight kept its state
  when you navigated away and back, instead of appearing to have never happened,
  and a startup race that could read a stale auto-lock setting is closed.
- **An implausible fee estimate is refused rather than paid.** A manifest
  transaction whose fee-rate estimate is outside a sane band is rejected before
  it is built, so a bad estimate cannot turn into a bad fee.
- **Less kept about a manifest transaction, for less time.** A completed manifest
  execution now stores only its txid. Everything else was reconstructible from
  the request being replayed, and keeping it made that table a readable record
  of what you had been doing for seven days.
- **Smaller things** — the Testnet/Regtest marker beside the logo is now a
  hard-edged caution placard in the console voice rather than a rounded pill; a
  transaction carrying a contract marker this version does not recognize reads as
  "Unrecognized contract" in plain text rather than an orange warning, and shows
  the bundle it referenced; and the Firefox build target is gone, so Apogee is
  Chrome-only.
