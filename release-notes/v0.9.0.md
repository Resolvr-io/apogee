# Apogee v0.9.0

- **A first-run sky that moves as one scene.** During the opening moon
  animation, the starfield now descends with the moon instead of remaining
  fixed behind it. Its depth is recalibrated so nearby stars move with visible
  parallax while stars near the horizon remain steadier, and the first meteor
  is timed to cross the sky as the Apogee logo appears.
- **A safer path from source to Chrome.** Releases are now built reproducibly
  from an exact reviewed commit, require a separate production approval, and
  create an immutable GitHub Release before those same verified bytes are sent
  to the Chrome Web Store. Short-lived credentials, serialized releases, and
  state-aware retries reduce the chance that a failed run can upload or submit
  the wrong package twice.
